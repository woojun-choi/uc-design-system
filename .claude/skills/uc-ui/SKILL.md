# uc-ui — uc-design-system으로 UI 만들기

DESIGN.md 전체를 읽지 말고, 필요한 장만 읽는다.

## 순서
1. `AGENTS.md`를 읽는다 (10줄 규칙 + 어디를 읽을지 표).
2. `DESIGN.md` **9장**(빠른 참조 + 예시)을 읽는다. 대부분 이걸로 충분하다.
3. 작업에 따라 필요한 장만 더 읽는다: 색 2장 · 글자 3장 · 컴포넌트 4장 · 여백 5장 · 그림자/모션 6장 · 문구 7장.
4. `src/components/ui/`에 쓸 컴포넌트가 있는지 확인하고 그걸 쓴다.
5. 코드를 쓴다 — 토큰 클래스만, 스타일은 `variant`·`tone`·`size`로.
6. `npm run lint`를 돌려 에러 0을 만든다. 에러 메시지가 고칠 방향과 DESIGN.md 장을 알려 준다.
7. 문구가 7장(해요체, 동사 버튼, 원인+해결 에러)에 맞는지 본다.

## 하지 않는 것
- hex·`rgb()`·임의 값(`p-[13px]`)·Tailwind 기본 색/크기(`bg-gray-100`, `text-sm`)
- 토큰 이름 지어내기, 비슷한 컴포넌트 새로 만들기
- `text-white` (→ `text-on-{tone}`), `outline-none`

## 토큰이 정말 모자라면
지어내지 말고 사용자에게 묻는다. 추가는 `tokens/`에서 하고 `npm run tokens`(대비 검사 포함) → DESIGN.md 해당 장을 같은 커밋에서 고친다.
