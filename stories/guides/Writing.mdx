# 문구 규칙

화면에 나오는 모든 글자에 적용한다 (원칙 12). 요약은 [DESIGN.md 7장](https://github.com/woojun-choi/uc-design-system/blob/main/DESIGN.md#7-writing).

## 기본 네 가지
| 규칙 | ✓ | ✗ |
|---|---|---|
| **해요체** | 사진을 올렸어요 | 사진이 업로드되었습니다 |
| **버튼은 동사로 끝낸다** | 저장하기 · 사진 추가하기 | 확인 · OK · 저장 |
| **같은 동작엔 같은 단어** | 늘 "삭제하기" | 삭제 / 지우기 / 제거 섞어 쓰기 |
| **에러는 원인 + 해결** | 파일이 50MB를 넘어요. 더 작은 파일로 다시 올려 주세요. | 오류가 발생했습니다 |

## 상황별

### 버튼
<div className="flex flex-wrap gap-2 rounded-md bg-layer-1 p-4">
  <Button>저장하기</Button>
  <Button variant="weak" tone="neutral">취소하기</Button>
  <Button variant="ghost" tone="danger">삭제하기</Button>
  <Button variant="outline" tone="neutral">다음으로</Button>
</div>

- 무엇이 일어나는지 동사로: "확인" 대신 그 동작 — "보내기", "바꾸기".
- 2~8자. 목적어가 필요하면 붙인다: "사진 추가하기".
- 진행 중엔 "~하는 중": "저장하는 중" (점 세 개 ✗).

### 동작 단어 사전
| 동작 | 쓰는 말 | 안 쓰는 말 |
|---|---|---|
| 저장 | 저장하기 | 저장, 확인, 완료 |
| 취소 | 취소하기 | 취소, 아니요 |
| 삭제 | 삭제하기 | 지우기, 제거, 삭제 |
| 생성 | 만들기 | 생성, 추가(목록에 새로 만들 때) |
| 수정 | 바꾸기 | 수정, 변경, 편집 |
| 업로드 | 올리기 | 업로드 |
| 닫기 | 닫기 | 확인(알림 닫을 때) |
| 다음 단계 | 다음으로 | 다음, 계속 |
| 공유 | 공유하기 | 공유 |

### 입력 에러
<div className="max-w-sm rounded-md bg-layer-1 p-4">
  <Input label="이메일" defaultValue="photo@" error="이메일 형식이 아니에요. @ 뒤에 주소까지 입력해 주세요." />
</div>

| ✓ | ✗ |
|---|---|
| 앨범 이름을 입력해 주세요. | 필수 항목입니다 |
| 20자까지 쓸 수 있어요. 지금 24자예요. | 글자 수 초과 |
| 이미 쓰고 있는 주소예요. 다른 주소를 입력해 주세요. | 중복된 값 |

### 확인 (Dialog)
- 제목은 **질문**, 대상은 **구체적으로**: "'여름의 끝' 앨범을 삭제할까요?"
- 설명에 **영향**과 **되돌릴 수 있는지**: "사진 12장이 함께 삭제되고, 되돌릴 수 없어요."
- 버튼은 "취소하기" + 동작 이름("삭제하기"). "예/아니요" ✗.

### 결과 알림
<div className="grid max-w-sm gap-2 rounded-md bg-layer-1 p-4">
  <Alert tone="success">저장했어요.</Alert>
  <Alert tone="danger" title="올리지 못했어요">인터넷 연결을 확인하고 다시 올려 주세요.</Alert>
</div>

- 성공은 짧게, 과거형: "저장했어요", "보냈어요".
- 실패는 "~하지 못했어요" + 원인 + 해결. 사용자 탓으로 쓰지 않는다 ("잘못 입력하셨습니다" ✗).

### 빈 화면
- 무엇이 없는지 + 다음 행동: "아직 사진이 없어요. 첫 사진을 올려 보세요." + [사진 올리기]
- 검색 결과 없음: "'필름'에 맞는 사진이 없어요. 다른 말로 찾아보세요."

### 라벨 · 도움말
- 라벨은 명사: "앨범 이름", "이메일".
- placeholder는 **예시**만: "예: 여름의 끝". 라벨·설명을 placeholder에 넣지 않는다.
- 도움말은 미리 알아야 할 제한: "20자까지 쓸 수 있어요".
