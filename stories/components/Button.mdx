# Button

누르면 **동작**이 일어나는 요소. 페이지 이동은 링크(`<a>`)이고, 모양만 버튼이 필요하면 `asChild`를 쓴다.

<Controls of={Stories.기본} />

## 언제 쓰나 / 언제 안 쓰나
| 쓴다 | 안 쓴다 |
|---|---|
| 저장, 삭제, 보내기 같은 동작 | 다른 페이지로 이동 → 링크 (`asChild`로 `<a>`) |
| 화면의 주요 동작 1개는 `solid` | 한 영역에 `solid` 여러 개 — 주요 동작이 흐려진다 |
| 보조 동작은 `weak` · `outline` · `ghost` | 상태 표시 → Badge |

## variant × tone
- **variant** = 강조 정도: `solid`(가장 강함) → `weak` → `outline` → `ghost`(가장 약함)
- **tone** = 의미: `brand`(기본, 주요 동작) · `neutral`(중립 동작) · `danger`(삭제·되돌릴 수 없음)

## Do · Don't
| ✓ Do | ✗ Don't |
|---|---|
| 버튼 글자는 **동사로 끝나게**: "저장하기", "사진 추가하기" | "확인", "OK", "예" — 무엇이 일어나는지 모름 |
| 삭제는 `tone="danger"` + 확인 Dialog | 삭제를 `brand`로, 확인 없이 |
| 진행 중엔 `loading` (글자는 그대로) | 진행 중에 글자를 "..."로 바꾸기 |
| 아이콘만 있는 버튼엔 `aria-label` | 아이콘만 두고 이름 없음 |
| `variant`·`tone`으로 스타일 조절 | `className`으로 색 덮어쓰기 |

## 접근성 체크
- [x] `<button>` 요소 — Enter·Space로 누름
- [x] 포커스 링: 전역 `:focus-visible` (`stroke.focus`, 고대비 3px)
- [x] `loading` → `aria-busy`, 누를 수 없음
- [x] `disabled` → 포커스 안 됨, 투명도 40%
- [x] 글자 대비: 모든 tone의 `fg.on-*` / `bg.*.solid` 4.5 이상 (`npm run check:contrast`)
- [x] 크기 `lg`(48px)는 터치 목표 44pt 이상 — 모바일 주요 버튼은 `lg`

## 코드
```tsx
import { Button } from '@/components/ui/button'

<Button>저장하기</Button>
<Button variant="weak" tone="neutral">취소하기</Button>
<Button tone="danger" loading>삭제하는 중</Button>
<Button asChild variant="outline"><a href="/about">소개 보기</a></Button>
```
