# Alert

화면 안에 **머무는** 알림. 처리 결과(저장했어요, 실패했어요)나 미리 알아야 할 안내를 보여 준다.

<Controls of={Stories.기본} />

## 언제 쓰나 / 언제 안 쓰나
| 쓴다 | 안 쓴다 |
|---|---|
| 양식을 저장한 뒤 결과 | 입력 칸 하나의 에러 → Input `error` |
| 화면 전체에 해당하는 경고·안내 | 상태 표시 2~6자 → Badge |
| | 흐름을 멈추고 확인받기 → Dialog |

## tone
아이콘은 tone에 따라 자동. 배경은 연한 tone, 글자는 기본 글자색이라 길어도 읽기 쉽다.

## Do · Don't
| ✓ Do | ✗ Don't |
|---|---|
| 제목은 결과를 해요체로: "저장했어요", "올리지 못했어요" | "성공", "Error" |
| 실패면 원인 + 해결: "파일이 50MB를 넘어요. 더 작은 파일로 다시 올려 주세요." | "오류가 발생했습니다" |
| 동작은 하나, `Button size="sm" variant="ghost"` | 버튼 여러 개 |
| 관련된 내용 바로 위·아래에 | 화면 맨 위에 쌓아 두기 |

## 접근성 체크
- [x] `danger`는 `role="alert"` — 나타나면 스크린 리더가 바로 읽음
- [x] 나머지는 `role="status"` — 하던 말이 끝나면 읽음
- [x] 아이콘은 `aria-hidden`, 뜻은 글자로
- [x] 글자 대비: 연한 tone 배경 위 `fg.default` · `fg.muted` 4.5 이상 (`npm run check:contrast`에 포함)

## 코드
```tsx
import { Alert } from '@/components/ui/alert'

<Alert tone="success" title="저장했어요">바뀐 프로필이 바로 보여요.</Alert>
<Alert tone="danger" title="올리지 못했어요" action={<Button size="sm" variant="ghost" tone="neutral">다시 시도하기</Button>}>
  파일이 50MB를 넘어요. 더 작은 파일로 다시 올려 주세요.
</Alert>
```
