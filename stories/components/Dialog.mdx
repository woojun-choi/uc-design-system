# Dialog

지금 흐름을 **멈추고** 확인이나 짧은 입력을 받는 창. 포커스 가두기 · Esc 닫기 · 바깥 스크롤 막기는 Radix가 맡는다.

<Canvas of={Stories.기본} />

## 언제 쓰나 / 언제 안 쓰나
| 쓴다 | 안 쓴다 |
|---|---|
| 되돌릴 수 없는 동작 확인 (삭제) | 단순 알림 → 화면 안 문구나 토스트 |
| 짧은 입력 1~3개 (이름 바꾸기) | 긴 양식 → 새 화면이나 Sheet (2차) |
| | Dialog 위에 또 Dialog |

## 삭제 확인 패턴 (`tone="danger"`)
<Canvas of={Stories.삭제_확인} />

1. 제목은 질문으로, **무엇이** 사라지는지: "'여름의 끝' 앨범을 삭제할까요?"
2. 설명에 영향과 **되돌릴 수 없음**: "사진 12장이 함께 삭제되고, 되돌릴 수 없어요."
3. 버튼: `취소하기`(weak · neutral) + `삭제하기`(solid · danger). 처음 포커스는 **취소하기**.
4. 진행 중엔 `loading`, 그동안 닫히지 않게.

## Do · Don't
| ✓ Do | ✗ Don't |
|---|---|
| 버튼은 동작 이름: "삭제하기", "바꾸기" | "확인" / "취소" 짝 — 무엇을 확인하는지 모름 |
| 제목(`DialogTitle`)은 꼭 둔다 | 제목 없이 내용만 |
| 주요 버튼은 오른쪽, 모바일에선 위 | 버튼 3개 이상 |

## 접근성 체크
- [x] 열리면 포커스가 Dialog 안으로, 닫히면 연 버튼으로 돌아감
- [x] Tab이 Dialog 밖으로 나가지 않음
- [x] Esc로 닫힘, 바깥 클릭으로 닫힘
- [x] `DialogTitle` → `aria-labelledby`, `DialogDescription` → `aria-describedby`
- [x] 닫기(X) 버튼에 `aria-label="닫기"`
- [x] 등장 애니메이션은 모션 토큰 — 모션 줄이기면 0

## 코드
```tsx
import { Dialog, DialogTrigger, DialogContent, DialogHeader, DialogTitle,
  DialogDescription, DialogFooter, DialogClose } from '@/components/ui/dialog'

<Dialog>
  <DialogTrigger asChild><Button variant="ghost" tone="danger">앨범 삭제하기</Button></DialogTrigger>
  <DialogContent tone="danger" showClose={false}>
    <DialogHeader>
      <DialogTitle>'여름의 끝' 앨범을 삭제할까요?</DialogTitle>
      <DialogDescription>사진 12장이 함께 삭제되고, 되돌릴 수 없어요.</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose asChild><Button variant="weak" tone="neutral">취소하기</Button></DialogClose>
      <Button tone="danger">삭제하기</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```
